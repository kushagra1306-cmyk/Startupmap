# Startup Map

A web application that enables startups to discover and connect with other businesses.

## Features
- User authentication
- Startup discovery
- Backend API integration

## Tech Stack
- Frontend: (React / HTML / etc.)
- Backend: Node.js, Express
- Database: (MongoDB / SQL)

## Project Structure
- /frontend
- /backend

## How to Run

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start
